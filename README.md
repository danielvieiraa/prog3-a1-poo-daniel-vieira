## Descrição do projeto

Este projeto consiste em um sistema de autenticação simples utilizando PHP orientado a objetos. Ele permite que usuários:

- Realizem cadastro (registro)
- Efetuem login
- Acessem um painel (dashboard) após o login
- Façam logout com segurança

O sistema também realiza validações básicas e mantém a sessão do usuário ativa após o login.

---

## Como Executar Localmente 

### Requisitos:
- **Laragon** instalado ([https://laragon.org](https://laragon.org))
- PHP 7.4 ou superior

### Passos:

1. **Coloque o projeto na pasta do Laragon**
   - Exemplo: `C:\laragon\www\`

2. **Acesse o sistema pelo navegador:**
   - Abra o navegador e vá até: `http://localhost/index.php`

3. **Pronto**
   - Você pode se cadastrar, fazer login e testar o funcionamento.
